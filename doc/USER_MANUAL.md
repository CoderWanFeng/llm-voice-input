## 简介

VoiceInput 是一款 macOS 语音输入工具，通过火山引擎豆包语音识别服务，将您的语音实时转换为文字，并自动粘贴到当前应用中。

**核心功能：**
- 🎙️ 实时语音转文字
- ⚡ 一键启动/停止录音
- 📋 自动粘贴到当前应用
- 🔊 实时识别结果反馈

## 权限配置

首次启动应用时，系统会依次请求以下权限，请务必全部授权：

### 1. 麦克风权限
- 弹窗提示："VoiceInput 想要访问麦克风"
- 操作：点击 **好**

### 2. 输入监控权限
- 弹窗提示："VoiceInput 想要监控此电脑的输入事件"
- 操作：点击 **打开系统设置**，在「输入监控」列表中勾选 VoiceInput

### 3. 辅助功能权限（可选，用于自动粘贴）
- 手动前往：「系统设置」→「隐私与安全性」→「辅助功能」
- 操作：勾选 VoiceInput

## 基本使用

### 录音流程

1. **准备**：将光标定位到需要输入文字的位置（如编辑器、聊天窗口等）
2. **开始录音**：按 `Option + K`
   - 屏幕底部会弹出悬浮面板，显示录音状态
   - 菜单栏图标变为 🎙️ 录音中状态
3. **说话**：清晰地说出要输入的内容
   - 悬浮面板会实时显示识别结果
4. **结束录音**：再次按 `Option + K`
   - 识别结果会自动写入剪贴板
   - 如果已授权辅助功能权限，会自动粘贴到光标位置

### 手动粘贴

如果自动粘贴失败（权限不足），可以手动按 `Cmd + V` 粘贴识别结果。

## 配置说明

### 配置文件位置

```
~/Library/Application Support/VoiceInput/config.json
```

### 配置格式

```json
{
  "app_id": "您的火山引擎 App ID",
  "access_token": "您的火山引擎 Access Token"
}
```

### 获取配置

1. 登录火山引擎控制台
2. 创建语音识别应用
3. 获取 `app_id` 和 `access_token`
4. 将凭证写入配置文件

### 配置检查

启动应用后，点击菜单栏 🎙️ 图标，如果配置正确会显示"配置检查通过"。

## 常见问题

### Q1: 快捷键没有响应？

**可能原因：**
- 应用未正确启动
- 输入监控权限未授权
- 快捷键被其他应用占用

**解决方案：**
1. 检查菜单栏是否显示 🎙️ 图标
2. 前往「系统设置 → 隐私与安全性 → 输入监控」确认 VoiceInput 已勾选
3. 尝试重启应用

### Q2: 录音后没有识别结果？

**可能原因：**
- 网络连接异常
- 配置凭证无效
- 麦克风未授权

**解决方案：**
1. 检查网络连接
2. 确认配置文件中的 `app_id` 和 `access_token` 正确
3. 检查麦克风权限是否已授权

### Q3: 自动粘贴不生效？

**可能原因：**
- 辅助功能权限未授权

**解决方案：**
1. 前往「系统设置 → 隐私与安全性 → 辅助功能」
2. 勾选 VoiceInput
3. 重启应用

## 故障排除

### 查看日志

应用运行日志会记录调试信息，帮助排查问题。日志包含：
- 状态转换记录
- 音频采集状态
- 识别结果输出
- 错误信息

### 重新授权权限

如果权限配置出现问题，可以尝试：

1. 退出 VoiceInput 应用
2. 前往「系统设置 → 隐私与安全性」
3. 在相关权限列表中移除 VoiceInput
4. 重新启动应用，按照提示重新授权

### 重置配置

如果配置文件损坏，可以删除后重新配置：

```bash
rm ~/Library/Application\ Support/VoiceInput/config.json
```
